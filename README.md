# Побег из комнаты

Небольшая квестовая игра на React: найди ключ и выберись из запертой комнаты, пока не закончилась энергия.

## Как играть

- Нажми **«Начать игру»**.
- **«Искать ключ»** тратит одну единицу энергии. Ключ находится после второго поиска.
- **«Отдохнуть»** восстанавливает одну единицу энергии.
- Когда найдёшь ключ, нажми **«Открыть дверь»**.
- Если энергия закончится, игра завершится поражением. После завершения можно начать заново.

## Запуск

Нужен установленный Node.js.

```bash
npm install
npm run dev
```

Для production-сборки выполни:

```bash
npm run build
```

## Технологии

React, Vite, JavaScript и CSS.
